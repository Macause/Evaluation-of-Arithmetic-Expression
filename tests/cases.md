# 計算器測試案例

共 60 筆有輸出的案例。依編號順序在同一次執行中測試，變數會跨行保留。

input.txt 第一行刻意留白，應無輸出。最後讀至 EOF 應正常結束。輸入檔只放程式支援的語法，說明放在本表。

三角函數以弧度計算，log 與 log10 為常用對數。本組使用可穩定比對的數值。一般非整數浮點測試應使用誤差容許值，例如 1e-12，而不是要求字串完全相同。

在 PowerShell 的專案目錄執行

```powershell
Get-Content tests/input.txt | python -X utf8 evaluator.py
```

將輸出與 expected.txt 對照。每個輸出行對應下表的一個案例，錯誤案例之後也必須繼續執行。
