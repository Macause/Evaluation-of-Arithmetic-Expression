# Evaluation of Arithmetic Expression

資料結構與圖形演算法第五次程式作業，以 Python 實作算術運算式求值與變數賦值。使用自行實作的鏈結串列 Stack，透過兩個堆疊處理運算優先順序、括號及函數。

## 執行方式

需要 Python 3.9 以上，使用標準函式庫即可執行。

```bash
python evaluator.py
```

每行輸入一個運算式或賦值敘述，按 Enter 計算。變數在同一次執行中保留。Windows 按 Ctrl+Z 再按 Enter 結束輸入，Linux 或 macOS 按 Ctrl+D。

例如依序輸入

```text
a = 1 + 2 * 3
b = sqrt(a + 2)
a + b
a = a + 1
```

輸出為

```text
a = 7
b = 3
10
a = 8
```

## 支援功能

| 類別 | 語法與規則 |
|---|---|
| 數值 | 十進位整數與小數，以 `float` 儲存，支援 `3.14`、`.5`、`5.` |
| 四則運算 | `+`、`-`、`*`、`/`，同級由左至右計算 |
| 括號 | 支援多層巢狀括號 |
| 一元負號 | `-3`、`2 * -3`、`-(1 + 2)`、`2--3` |
| 次方 | 使用 `^`，由右至左結合，`2^3^2` 得到 `512` |
| 負號與次方 | `-2^2` 得到 `-4`，`(-2)^2` 得到 `4`，`2^-2` 得到 `0.25` |
| 變數 | 單一小寫字母 `a`～`z`，例如 `a = 3`、`a = a + 1` |
| 三角函數 | `sin(x)`、`cos(x)`、`tan(x)`，參數使用弧度 |
| 對數 | `ln(x)` 為自然對數，`log(x)` 與 `log10(x)` 為常用對數 |
| 平方根 | `sqrt(x)` |

函數必須使用括號，括號內可以包含運算式或其他函數，例如 `sqrt(1 + sqrt(9))` 得到 `2`。

## 實作流程

1. `tokenize()` 從左到右掃描字串，將數字轉成 `float`，保留運算子、括號及名稱。
2. `evaluate_statement()` 判斷輸入是否包含賦值，並檢查左側是否為單字母變數。
3. `classify_minus()` 根據所在位置，把一元負號標記為 `NEG`。
4. `evaluate()` 用數值堆疊儲存運算元與中間結果，用運算子堆疊儲存待執行的運算。
5. 讀到二元運算子時比較優先順序，讀到右括號時完成該括號內的運算。函數在其參數的右括號關閉後執行。
6. 賦值右側計算成功後，才寫入共用的變數表。若失敗，原值會保留。

優先順序由高至低為次方、一元負號、乘除、加減。一元負號入堆疊時會等待後方運算元，因此也能處理負指數。

每個運算子至多入堆疊及出堆疊各一次。將數值運算視為常數成本時，長度為 n 的一行輸入，其時間與額外空間皆為 O(n)。變數表最多儲存 26 個值。

## 測試

在專案根目錄的 PowerShell 執行

```powershell
Get-Content tests/input.txt | python -X utf8 evaluator.py
```

在 Bash 或 Windows cmd 可使用輸入重新導向

```bash
python -X utf8 evaluator.py < tests/input.txt
```

輸出應與 `tests/expected.txt` 一致。這 60 筆案例須在同一次執行中依序測試，部分案例會引用前面建立的變數。案例涵蓋運算優先順序、括號、負號、函數、跨行變數、錯誤恢復及失敗賦值的狀態保留。另驗證空白行跳過與 EOF 正常結束。各案例說明見 [tests/cases.md](tests/cases.md)。

## 錯誤處理與使用限制

- 使用未定義變數、除以零、括號不匹配、缺少運算元或運算子時，輸出錯誤訊息並繼續下一行。
- 賦值格式為 `單一小寫字母 = 運算式`。多字母變數及連鎖賦值會報錯。
- 對數參數必須大於零，平方根參數必須大於或等於零。次方產生複數時會報錯。
- `tan` 在 `abs(cos(x)) < 1e-15` 時視為太接近奇點並報錯。
- 需明寫乘號，例如 `2 * (3 + 4)`。目前的輸入語法未涵蓋科學記號、一元正號與複數。
- 使用浮點數計算，可能有捨入誤差。超大數值受 Python 浮點範圍限制，部分運算可能溢位為無限大，程式目前尚未統一攔截所有非有限結果。
